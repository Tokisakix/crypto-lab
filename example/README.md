# Crypto Lab Example

`example` 文件夹存放了中山大学 2024 年《现代密码学》的所有教材算法的 Python 实现

## 维吉尼亚密码

代码实现位于 [vigenere.py](impl/vigenere.py)

```bash
cd example
python main.py --type vigenere
```
